## ଏହା କ’ଣ

OmniRoute ଏକ **Obsidian** ଭଲ୍ଟ ସହିତ **ପ୍ରସଙ୍ଗ ଉତ୍ସ** ଭାବରେ ସଂଯୋଗ କରେ — ଏହା ଏକ ସ୍ଥାନୀୟ Markdown
ଜ୍ଞାନ ଭଣ୍ଡାର, ଯାହାକୁ ଏଜେଣ୍ଟମାନେ ବିଲ୍ଟ-ଇନ୍ MCP ସର୍ଭର୍ ମାଧ୍ୟମରେ ପଢ଼ନ୍ତି ଏବଂ ଲେଖନ୍ତି। ଏହି
ଇଣ୍ଟିଗ୍ରେସନ୍ ଡେସ୍କଟପ୍ ଆପ୍ ଭିତରେ ଚାଲୁଥିବା **Obsidian Local REST API** କମ୍ୟୁନିଟି ପ୍ଲଗ୍ଇନ୍
ସହିତ ଯୋଗାଯୋଗ କରେ, ଯାହାଦ୍ୱାରା ଏଜେଣ୍ଟମାନେ ନୋଟ୍ ସନ୍ଧାନ କରିପାରନ୍ତି, ଫାଇଲ୍
ପଢ଼ି/ଲେଖି/ପ୍ୟାଚ୍ କରିପାରନ୍ତି, ଭଲ୍ଟର ତାଲିକା ଦେଖିପାରନ୍ତି, ଦୈନିକ/ସାପ୍ତାହିକ ପର୍ଯ୍ୟାୟିକ
ନୋଟ୍ ସହ କାମ କରିପାରନ୍ତି, ଟ୍ୟାଗ୍ ପରିଚାଳନା କରିପାରନ୍ତି, Obsidian କମାଣ୍ଡ ଚଲାଇପାରନ୍ତି ଏବଂ
(ଇଚ୍ଛାଧୀନ ଭାବେ) ଦ୍ୱିଦିଶୀୟ ଡେସ୍କଟପ୍↔ମୋବାଇଲ୍ ଭଲ୍ଟ ସିଙ୍କ୍ ସମନ୍ୱୟ କରିପାରନ୍ତି।

କ୍ଲାଏଣ୍ଟ (`src/lib/obsidian/api.ts`) Local REST APIକୁ ନିମ୍ନଲିଖିତ ସୁବିଧା ସହିତ ରାପ୍ କରେ:

- ଅସ୍ଥାୟୀ `5xx` ପାଇଁ **ବ୍ୟାକଅଫ୍ ସହ ପୁନଃପ୍ରୟାସ**, `AbortController` ମାଧ୍ୟମରେ **30-ସେକେଣ୍ଡର ଟାଇମ୍ଆଉଟ୍**।
- **ଟାଇପ୍ଯୁକ୍ତ ତ୍ରୁଟି ବର୍ଗୀକରଣ** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`।
- ଏକ **ସହଜବୋଧ୍ୟ "Obsidian ସହିତ ସଂଯୋଗ ହୋଇପାରୁନାହିଁ" ସୂଚନା**, ଯାହା ସାଧାରଣ ପୋର୍ଟ ତ୍ରୁଟି
  (HTTP `27123`ରେ, `27124`ରେ ଥିବା MCP ଏଣ୍ଡପଏଣ୍ଟରେ **ନୁହେଁ**) ଏବଂ Tailscale ଫର୍ମକୁ ଉଲ୍ଲେଖ କରେ।
- ଭଲ୍ଟ-ସାପେକ୍ଷ **ପାଥ୍ ଏନ୍କୋଡିଂ**, ଯାହାଦ୍ୱାରା ସ୍ପେସ୍/ସ୍ଲାସ୍ ଥିବା ନୋଟ୍ ପାଥ୍ଗୁଡ଼ିକ ସୁରକ୍ଷିତ ରହେ।

## ସେଟଅପ୍।

ସେଠାରେ ଅଛି।** କ environment ଣସି ପରିବେଶ ପରିବର୍ତ୍ତନଶୀଳ ନୁହେଁ।** Obsidian ଟୋକେନ୍ କିମ୍ବା ଆଧାର URL — ପାଇଁ ଉଭୟ SQLite `key_value` ସାରଣୀରେ (ନାମ ସ୍ଥାନ `obsidian`) `src/lib/db/obsidian.ts` ମାଧ୍ୟମରେ ଗଚ୍ଛିତ। ଟୋକନ୍ ହେଉଛି।** ବିଶ୍ରାମରେ ସଂଗୁପ୍ତ।** (AES-256-GCM, ସାଧା ପାଠ୍ୟ ପଛୁଆ-ସୁସଙ୍ଗତ ଫଲବ୍ୟାକ୍ ସହିତ)। ରୁ ବିନ୍ୟାସ କରନ୍ତୁ** ପ୍ରସଙ୍ଗ ଉତ୍ସ।** ଏଣ୍ଡପଏଣ୍ଟ ଡ୍ୟାସବୋର୍ଡର ଟ୍ୟାବ୍ (`ObsidianSourceCard`), କିମ୍ବା REST API ସେଟିଙ୍ଗ୍ ମାଧ୍ୟମରେ।

> [!IMPORTANT]
> The**Obsidian ସ୍ଥାନୀୟ REST API** ପ୍ଲଗଇନ୍ ସଂସ୍ଥାପିତ ଏବଂ ଚାଲିବା ଜରୁରୀ। ଏହାର REST ଇଣ୍ଟରଫେସ୍ ଶୁଣେ।**HTTP `127.0.0.1:27123`** (ଡିଫଲ୍ଟ ଆଧାର URL) ପୋର୍ଟ `27124` ହେଉଛି ଏକ _ ପୃଥକ_ MCP/HTTPS ଶେଷ ପଏଣ୍ଟ ଏବଂ ସେଟିଂ ମାର୍ଗ ଦ୍ୱାରା ସ୍ପଷ୍ଟ ଭାବରେ ପ୍ରତ୍ୟାଖ୍ୟାନ। ଯଦି ଅନ୍ୟ ଉପକରଣରୁ ସଂଯୋଗ ହେଉଛି, `http://<tailscale-ip>:27123` ବ୍ୟବହାର କରନ୍ତୁ।

### ବିନ୍ୟାସ କୀ (SQLite `key_value`, namespace `obsidian`)

| ଚାବି              | ଉଦ୍ଦେଶ୍ୟ                                             | ଏନକ୍ରିପ୍ଟ ହୋଇଛି। |
| ----------------- | ---------------------------------------------------- | ---------------- |
| `api_key`         | ସ୍ଥାନୀୟ REST API ଧାରକ ଟୋକେନ୍।                        | ହଁ               |
| `base_url`        | REST ଆଧାର URL (ଡିଫଲ୍ଟ `http://127.0.0.1:27123`)      | ନା               |
| `vault_path`      | ଭାଲ୍ଟ ଡିରେକ୍ଟୋରୀକୁ ସଂପୂର୍ଣ୍ଣ ପଥ (ସିଙ୍କ ପାଇଁ)         | ନା               |
| `webdav_username` | ସୃଷ୍ଟି ହୋଇଥିବା WebDAV ଉପଯୋଗକର୍ତ୍ତା ନାମ (ଭାଲ୍ଟ ସିଙ୍କ) | ନା               |
| `webdav_password` | ସୃଷ୍ଟି ହୋଇଥିବା WebDAV ପାସୱାର୍ଡ (ଭାଲ୍ଟ ସିଙ୍କ)         | ହଁ               |
| `webdav_enabled`  | WebDAV ଭାଲ୍ଟ ସିଙ୍କ ସକ୍ଷମ ହୋଇଛି କି ନାହିଁ।             | ନା               |

### REST ମାଧ୍ୟମରେ ବିନ୍ୟାସ କରନ୍ତୁ।

```bash
# Save + validate the Local REST API token (POST validates via a status check)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Check connection status (returns connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Disconnect (clears the stored token)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

ସମସ୍ତ ପଦ୍ଧତି ଡ୍ୟାସବୋର୍ଡ ପ୍ରାମାଣିକିକରଣ ଆବଶ୍ୟକ କରେ। `POST` ପୋର୍ଟ `27124` ରେ ଯେକ z ଣସି URL ପ୍ରତ୍ୟାଖ୍ୟାନ କରେ ଏବଂ ସ୍ଥିର ହେବା ପୂର୍ବରୁ ସ୍ଥାନୀୟ REST API ସ୍ଥିତି ଶେଷ ପଏଣ୍ଟକୁ କଲ କରି ଟୋକେନ୍ ବ valid ଧ କରେ।

### WebDAV ଭାଲ୍ଟ ସିଙ୍କ୍।

`src/app/api/settings/obsidian/webdav/route.ts` ଏକ ଇଚ୍ଛାଧୀନ WebDAV- ସମର୍ଥିତ ଭାଲ୍ଟ ସିଙ୍କ ( `src/lib/obsidianSync.ts` ଦ୍ୱାରା ଚାଳିତ) ପରିଚାଳନା କରେ। ଏହାକୁ ସକ୍ଷମ କରିବା ଏକ ସ୍ଥାନୀୟ ଭାଲ୍ଟ ଡିରେକ୍ଟୋରୀରେ OmniRoute ସୂଚିତ କରେ ଏବଂ ଏକ ଅନିୟମିତ WebDAV username/password ଯୁଗଳକୁ ମିନିଟ୍ କରେ:

```bash
# Enable WebDAV sync for a vault directory (mints username/password)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Get WebDAV sync status (credentials returned only while enabled)
curl http://localhost:20128/api/settings/obsidian/webdav

# Disable WebDAV sync (clears credentials + managed .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### ସୁରକ୍ଷା ଏବଂ ପରିବହନ

WebDAV ପ୍ରାମାଣିକିକରଣ ପ୍ରତି IP ବିଫଳତା ଟ୍ରାକିଂ ଏବଂ ଲକଆଉଟ୍ (60 ସେକେଣ୍ଡ ୱିଣ୍ଡୋ ମଧ୍ୟରେ 10 ଟି ବିଫଳ ପ୍ରୟାସ `429 Too Many Requests` ଏବଂ `Retry-After` ସହିତ 5 ମିନିଟର ଲକଆଉଟ୍ ଟ୍ରିଗର କରିଥାଏ)। କାରଣ WebDAV Basic ଳିକ ପ୍ରାମାଣିକିକରଣ ପ୍ରମାଣପତ୍ର ପଠାଇଥାଏ, ଲୁକବ୍ୟାକ୍ ବାହାରେ WebDAV ଏଣ୍ଡପଏଣ୍ଟକୁ ପ୍ରବେଶ କରିବା ସମୟରେ TLS (କିମ୍ବା Tailscale କିମ୍ବା Cloudflare ଟନେଲ ପରି ଏକ ସୁରକ୍ଷିତ ଟନେଲ ଉପରେ ରାଉଟିଙ୍ଗ୍) ସମାପ୍ତ କରିବାକୁ ଦୃ strongly ଭାବରେ ପରାମର୍ଶ ଦିଆଯାଏ।

### ପ୍ରତି- API- କି ପ୍ରସଙ୍ଗ ଉତ୍ସ (ବ al କଳ୍ପିକ)

Obsidian ବିନ୍ୟାସକୁ ସ୍କପ୍ କରାଯାଇପାରିବ।** API କି ପାଇଁ** `api_key_context_sources` ଟେବୁଲ୍ (`src/lib/db/apiKeyContextSources.ts`) ମାଧ୍ୟମରେ। ଯେତେବେଳେ ଏକ MCP କଲ୍ ଏକ ପ୍ରାମାଣିକ API କି id ବହନ କରେ, `getObsidianConfigForApiKey()` ସେହି ଚାବିର ନିଜସ୍ୱ token/base-URL/vault-path (`source: "api_key"`) କୁ ପସନ୍ଦ କରେ ଏବଂ ଅନ୍ୟଥା ବିଶ୍ global ବିନ୍ୟାସ (`source: "global"`) କୁ ଫେରିଯାଏ।

ଅଣ-ସିଙ୍କ୍ MCP ଉପକରଣଗୁଡ଼ିକ ଏହି ବିନ୍ୟାସ ପ reading ିବା ପୂର୍ବରୁ ଏକ ସମାଧାନ ହୋଇଥିବା କଲର୍ ପରିଚୟ ଆବଶ୍ୟକ କରେ। ପରିଚୟ ବିନା କଲ୍ କରୁଥିବା ବ୍ୟକ୍ତି `Obsidian API token not configured` ଗ୍ରହଣ କରନ୍ତି, ଏବଂ କ v ଣସି ଭାଲ୍ଟ ଅନୁରୋଧ ପଠାଯାଏ ନାହିଁ। HTTP କଲର୍ମାନେ ସେମାନଙ୍କର ଅନୁରୋଧ ପ୍ରମାଣପତ୍ର ମାଧ୍ୟମରେ ସମାଧାନ କରନ୍ତି; stdio କଲର୍ ଗୁଡିକ `OMNIROUTE_API_KEY` କିମ୍ବା `ROUTER_API_KEY` ମାଧ୍ୟମରେ ସମାଧାନ କରିପାରିବେ। ଏକ ସମାଧାନ ହୋଇନଥିବା HTTP କଲର୍ ସର୍ଭରର ପରିବେଶ ପରିଚୟକୁ ଉତ୍ତରାଧିକାରୀ କରିପାରିବ ନାହିଁ। ପ୍ଲେସହୋଲ୍ଡର IDs କେବଳ ପ୍ରବେଶକୁ ଅନୁମତି ଦିଏ ନାହିଁ; ଏକ ବ valid ଧ ପରିବେଶ ପରିଚୟ ଯାହାକି `env-key` କୁ ସମାଧାନ କରେ ସମର୍ଥିତ ରହିଥାଏ। ପ୍ରତି କୀ Obsidian ବିନ୍ୟାସ ବିନା ପ୍ରାମାଣିକ ଚାବିଗୁଡ଼ିକ ବିଶ୍ୱବ୍ୟାପୀ ଅବନତି ବଜାୟ ରଖେ। ଚାରୋଟି `obsidian_sync_*` ସାଧନଗୁଡ଼ିକ ସେମାନଙ୍କର ପୃଥକ ସିଙ୍କ-ଟୋକେନ୍ ଆଚରଣ ରଖନ୍ତି।

- **ନୋଟ୍ ରଚନା / ଜର୍ନାଲିଂ** — ଏଜେଣ୍ଟ ଆଉଟପୁଟ୍, ସାରାଂଶ କିମ୍ବା ଦୈନିକ ନୋଟ୍
  (`obsidian_get_periodic_note`)କୁ ଭଲ୍ଟରେ ଲଗ୍ କରିବା ପାଇଁ `obsidian_write_note`, `obsidian_append_note`, କିମ୍ବା
  ସୂକ୍ଷ୍ମ ପରିବର୍ତ୍ତନ ପାଇଁ `obsidian_patch_note`।
- **ଭଲ୍ଟ ନେଭିଗେସନ୍** — ପଢ଼ିବା/ଲେଖିବା ପୂର୍ବରୁ ଗଠନ ଅନୁସନ୍ଧାନ କରିବା ପାଇଁ `obsidian_list_vault`, `obsidian_get_document_map`, ଏବଂ
  `obsidian_get_tags`।
- **Obsidian ସ୍ୱୟଂଚାଳନ** — ଏକ ଏଜେଣ୍ଟରୁ ପ୍ଲଗଇନ୍/କମାଣ୍ଡଗୁଡ଼ିକୁ ପରିଚାଳନା କରିବା ପାଇଁ `obsidian_list_commands` + `obsidian_execute_command`;
  UIରେ ଏକ ନୋଟ୍ ଦେଖାଇବା ପାଇଁ `obsidian_open_file`।
- **ମୋବାଇଲ୍ ସିଙ୍କ୍** — WebDAV ସିଙ୍କ୍ ସକ୍ଷମ କରନ୍ତୁ, ତା’ପରେ ଡେସ୍କଟପ୍↔ମୋବାଇଲ୍ ମଧ୍ୟରେ ସମନ୍ୱୟ ଏବଂ ଦ୍ୱନ୍ଦ୍ୱ ସମାଧାନ ପାଇଁ `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  ବ୍ୟବହାର କରନ୍ତୁ।
